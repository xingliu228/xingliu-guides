01 / SETUP

安装与启动

安装即用：获取「星夜创作」安装包后双击安装，从桌面快捷方式启动。无需手动安装 Python 或其他运行环境；缺少 WebView2 组件时，安装器会自动联网补装。

  1. 双击「星夜创作」安装包，按提示完成安装；出现系统权限弹窗时确认允许。
  2. 从桌面快捷方式或开始菜单启动「星夜创作」，进入启动中心。
  3. 点击「启动本地服务」。首次启动会自动下载所需浏览器，请保持网络畅通并等待就绪。
  4. 服务就绪后点击「打开工作台」，在浏览器中进入本机工作台（地址 127.0.0.1:8000，指的是你自己的电脑，不是公共网站）。

完成标志：能看到工作概览，并打开「平台账号」页面。第一次列表为空是正常的。

日常启动与停止

日常从桌面快捷方式打开启动中心，一键启动本地服务。暂时不用时可收起到系统托盘；需要完全停止时，在启动中心选择「停止并退出」。仅关闭网页并不会停止后台服务。

应用更新

应用会定期检查新版本；有可用更新时，右下角会出现更新提示，按提示下载安装即可。升级前会自动备份配置与数据库，已下载内容与账号资料保留；更新完成后重新启动，检查账号、配置和历史记录是否正常。

启动或连接异常时

先在启动中心查看运行记录与诊断信息，确认服务状态；再按常见问题排查。仍无法解决时，按文末方式导出运行日志联系我们。

02 / ACCOUNT

登录视频号：扫码进入创作者助手

入口：选择视频号 → 平台账号 → 添加账号

  1. 把平台切换为「视频号」，打开「平台账号 → 添加账号」，使用扫码入口。
  2. 在弹出的创作者助手页面中，按提示完成微信确认。
  3. 回到账号列表检查状态，确认昵称与状态正常。

完成标志：账号出现在列表中，状态检测正常，并能在「我的内容」与「发布」中被选中。

登录失效时从账号列表重新扫码登录，不要为了修复登录删除整个数据目录。

03 / FIRST RESULT

第一个任务：同步自己的作品

视频号版的第一个任务不是下载，而是把本账号的内容同步进来，确认账号链路可用。

  1. 进入「我的内容」，选择刚登录的视频号账号。
  2. 同步自己的作品，然后依次检查作品、数据或评论标签。
  3. 新账号没有作品时，空列表是正常情况，不必为测试而发布内容。

完成标志：能进入「我的内容」并选中自己的视频号，同步不报错；有作品时可以看到作品、数据与评论。账号链路已跑通。

下一步：要发布内容，看发布与接收转发；功能细节见作品、数据与评论。

本账号作品、数据与评论

入口：我的内容 → 选择视频号账号 → 选择标签

  1. 进入「我的内容」，确认平台和账号都是你的视频号。
  2. 按页面可见标签，同步自己的作品、数据和评论。
  3. 登录失效时回到「平台账号」重新登录；不要改填他人主页作为监控目标——视频号版不支持监控他人作品。

能力边界：这里的数据只关于你自己的账号。想看别人的更新，请使用站内其他平台教程中对应的监控能力，视频号没有此功能。

发布与接收转发

入口：发布 → 撰写内容；结果在「发布记录」查看

  1. 确认创作者登录有效（账号列表状态正常），进入「发布」选择账号。
  2. 添加素材与文案，检查预览；确认无误后仅提交一次。
  3. 在「发布记录」查看进度，再到创作者助手核对发布结果。

接收转发：已下载且有权使用的抖音作品，可从应用支持的入口转发到视频号。这只代表「能发到视频号」，不代表支持下载视频号内容。提交成功也不代表已通过平台审核或公开可见，以创作者助手中的实际状态为准。

NOTICE / 限制与注意

限制与注意

  • 只支持本账号数据，不支持监控或下载他人作品。
  • 不支持关键词采集、弹幕监控或自动评论。
  • 没有作品时保持空列表即可，不必为测试而发布内容。
  • 发布依赖创作者登录有效；提交成功不代表通过平台审核或公开可见，以创作者助手核对结果为准。
  • 本地任务依赖本地服务运行：关闭服务或电脑休眠后，任务不会继续执行。
FAQ / 常见问题

常见问题

浏览器查找快捷键：Windows / Linux 按 Ctrl + F，macOS 按 ⌘ + F，搜索错误关键词。

打开工作台提示连接失败

确认启动中心仍在运行、本地服务处于「运行中」，首次启动的依赖与浏览器下载已完成。尽量使用启动中心的「打开工作台」按钮进入。127.0.0.1 指本机，不要在另一台电脑上访问这个地址。

作品列表是空的，正常吗

正常。视频号版只同步本账号内容；新账号或还没有发布过作品时，空列表就是真实状态，不必为测试而发布内容。登录失效时重新扫码登录即可。

能监控或下载别人的视频号内容吗

不能。视频号版只支持本账号的作品、数据与评论，不提供他人作品的监控或下载；关键词采集、弹幕监控与自动评论也不在支持范围内。

发布后在哪里核对结果

在「发布记录」查看进度，并到微信「创作者助手」核对作品与审核状态；提示「结果待确认」时先核对，不要重复提交，以免重复发布。
