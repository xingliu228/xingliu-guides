01 / SETUP

安装与启动

安装即用：获取「星流创作」安装包后双击安装，从桌面快捷方式启动。无需手动安装 Python 或其他运行环境；缺少 WebView2 组件时，安装器会自动联网补装。

  1. 双击「星流创作」安装包，按提示完成安装；出现系统权限弹窗时确认允许。
  2. 从桌面快捷方式或开始菜单启动「星流创作」，进入启动中心。
  3. 点击「启动本地服务」。首次启动会自动下载所需浏览器，请保持网络畅通并等待就绪。
  4. 服务就绪后点击「打开工作台」，在浏览器中进入本机工作台（地址 127.0.0.1:8000，指的是你自己的电脑，不是公共网站）。

完成标志：能看到工作概览，并打开「平台账号」页面。第一次列表为空是正常的。

日常启动与停止

日常从桌面快捷方式打开启动中心，一键启动本地服务。暂时不用时可收起到系统托盘，任务继续运行；需要完全停止时，在启动中心选择「停止并退出」。仅关闭网页并不会停止后台服务。

应用更新

应用会定期检查新版本；有可用更新时，右下角会出现更新提示，按提示下载安装即可。升级前会自动备份配置与数据库，已下载内容与账号资料保留；更新完成后重新启动，检查账号、配置和历史记录是否正常。

启动或连接异常时

先在启动中心查看运行记录与诊断信息，确认服务状态；再按常见问题排查。仍无法解决时，按文末方式导出运行日志联系我们。

02 / ACCOUNT

登录抖音账号

入口：顶部选择抖音 → 平台账号 → 添加账号

  1. 在顶部把平台切换为「抖音」，打开「平台账号 → 添加账号」。
  2. 按用途选择登录方式：「扫码登录」获得读取能力，用来采集与下载；要发布作品，选择或另行完成「创作者登录」。
  3. 在弹出的浏览器窗口按提示扫码、确认或完成验证，不要提前关闭登录窗口。
  4. 回到账号列表检测状态，确认昵称与状态正常；必要时刷新资料或重新检测。

完成标志：账号出现在列表中，状态检测正常，并能在创建任务时被选中。

两种登录各有用途：扫码解决「读取」，创作者登录解决「发布」。能下载、能采集，不代表已经能发布；发布前先确认创作者登录有效。

Cookie 登录是进阶选项，新手先用扫码与创作者登录即可。登录失效时从账号列表重新登录，不要为了修复登录删除整个数据目录。

03 / FIRST RESULT

第一个任务：下载一条自己的作品

先用你自己拥有或获准保存的一条抖音作品，验证「本地服务 → 账号 → 任务 → 文件」整条链路。

  1. 在抖音复制自己一条作品的完整分享文案，不必手动删掉其中的文字。
  2. 打开「链接下载」，粘贴分享内容，选择刚登录的账号，其余选项先保留默认。
  3. 提交后等待页面返回结果，不要连续点击。
  4. 到下载历史核对保存位置，打开电脑上的实际文件确认可以播放。

完成标志：下载历史显示完成，实际文件能正常打开。链路已跑通，后面的功能都建立在这条链路上。

下一步：想持续发现新作品，看作品监控；想按关键词一次收集一批，看关键词批量采集。下载的详细选项见链接下载。

链接下载：保存已知作品

入口：链接下载

  1. 复制作品完整分享文案或链接，粘贴到输入框。
  2. 按需选择账号与下载选项，提交后等待结果。
  3. 在下载历史查看状态与保存路径，成功后打开实际文件核对。

下载有断点续传和失败重试机制；链接失效或登录失效导致的失败，需要先修复原因再重试，而不是反复提交。默认下载内容位于 data/media/ 下，修改过下载目录时以界面配置的实际路径为准。

已下载且有权使用的作品，可按应用内提供的入口转发到小红书或视频号，见发布与转发。

作品监控：持续发现新作品

入口：作品监控 → 新建作品监控

  1. 新建作品监控，粘贴创作者主页的完整分享文案，使用「识别」并检查识别结果是否正确。
  2. 选择执行账号，设置检查频率与自动下载范围；「首次历史回填」先选最近 5 条或不回填。
  3. 保存后在「监控目标」查看执行状态，符合条件的新内容出现在「作品记录」。

为什么新建后看不到旧作品？默认监控订阅之后的新内容，历史回填是可选项，两件事分开看待。没有新内容、尚未到检查时间，都会暂时没有记录。

完成标志：目标出现在列表中；执行后有检查状态，有符合条件的新作品时进入作品记录。不需要继续监控时，暂停该目标，不要只关网页。

第一次建议用「每 30 分钟」或「每小时」这类低频设置，确认跑通后再增加目标或提高频率。

关键词批量采集：一次性收集一批结果

入口：关键词采集 → 新建关键词采集

  1. 新建关键词采集，第一次先输入 1 个关键词，「每词作品数」设为 5 左右，便于核对结果。
  2. 按需设置评论数、是否包含二级评论与媒体下载；不需要的选项保持关闭。
  3. 任务结束后检查结果与错误信息，确认后导出 Excel。
  4. 需要更多数据时，对已结束任务编辑配置并保留结果去重续跑，避免重复新建相同任务。

这是一次性任务，不是定时监控。采集数量是上限，不代表平台全部内容；实际结果受平台排序、登录状态与当前可见内容影响，少于设置数量不一定是故障。想持续盯一个创作者，请用作品监控。

评论与弹幕：读取互动内容

入口：评论监控 / 弹幕监控 → 新建

  1. 评论监控：选择「指定作品」或「账号近期作品」目标，填写对应链接，选择执行账号后保存。
  2. 弹幕监控：选择目标视频与来源——自己的视频使用创作中心来源，公开视频使用播放器来源。
  3. 在「评论记录」「弹幕记录」查看结果；弹幕记录中的时间指视频内的播放位置，不是发布时间。

弹幕监控针对短视频，直播弹幕不在支持范围内。评论与弹幕监控只负责读取和保存，不会自动发出回复；自动回复见自动评论。

发布与转发

入口：发布 → 撰写内容；结果在「发布记录」查看

  1. 确认账号已完成创作者登录且状态正常，进入「发布」选择发布账号。
  2. 添加素材与文案，在预览区核对内容；确认无误后仅提交一次。
  3. 在「发布记录」查看进度，并到抖音核对作品与审核状态。
  4. 已下载且有权使用的作品，可按应用内提供的入口转发到小红书或视频号。

遇到「结果待确认」：先去抖音检查是否已经发出，不要直接重复提交，以免重复发布。任务提交成功，不代表已通过平台审核或公开可见。

我的内容与私信

入口：我的内容 → 选择账号 → 选择标签

  1. 进入「我的内容」，选择抖音账号，按需要同步作品、关注、粉丝或私信会话。
  2. 处理私信时，先同步并查看会话，确认对象与上下文，再撰写回复或执行账号动作。
  3. 关注任务结果：遇到「冷却」或「结果待确认」时，先核对平台实际状态再决定下一步，不要连续重复操作。

发送与账号动作受间隔与风控约束，出现平台验证提示时在当前浏览器窗口处理，不要不断重试。

自动评论

入口：自动评论 → 新建评论规则；审核在「任务与审核」

  1. 新建规则：选择执行账号与评论目标，填写评论模板；新建后规则先保持关闭。
  2. 小范围试跑：检查命中的对象与生成的文案，到「任务与审核」处理需要人工审核的任务。
  3. 确认行为符合预期后再启用规则；实际发送仍受审核、发送间隔与平台风控约束。

「已启用」不等于「立刻发送」。规则、审核、队列与平台提交是不同阶段；排队原因到任务队列中查看。出现平台验证码或拒绝提示时，先处理提示，不要连续重试。不需要时关闭规则，并检查队列里是否还有待处理任务。

NOTICE / 限制与注意

限制与注意

  • 关键词批量采集是一次性任务，作品监控才是持续检查；不要用采集功能实现盯更新的需求。
  • 弹幕监控针对短视频，不是直播弹幕。
  • 采集数量是上限，不代表平台全部内容；结果受排序、登录状态与可见性影响。
  • 发布与转发要求创作者登录有效；提交成功不代表通过平台审核或公开可见。
  • 自动发送类任务受审核、间隔与风控冷却约束；遇到平台验证时先在当前窗口处理，保留默认保护设置，优先降低任务规模与频率，而不是把限制调为零。
  • 本地任务依赖本地服务运行：关闭服务或电脑休眠后，任务不会继续执行；定时与排队任务请保持服务运行。
FAQ / 常见问题

常见问题

浏览器查找快捷键：Windows / Linux 按 Ctrl + F，macOS 按 ⌘ + F，搜索错误关键词。

打开工作台提示连接失败

确认启动中心仍在运行、本地服务处于「运行中」，首次启动的依赖与浏览器下载已完成。尽量使用启动中心的「打开工作台」按钮进入。127.0.0.1 指本机，不要在另一台电脑上访问这个地址。

采集结果比设置的数量少

数量是上限，不是保证值；受平台排序、登录状态与当前可见内容影响。先核对任务错误信息与账号状态，若无明显错误，少量缺口属于正常现象，可用「保留结果去重续跑」补采。

弹幕监控没有结果

先检查视频与来源是否匹配：自己的视频使用创作中心来源，公开视频使用播放器来源。弹幕监控只针对短视频；直播弹幕不在支持范围内。

发布提示「结果待确认」或失败

先到抖音核对作品是否已发出，确认后再决定下一步，不要立即重复提交。发布依赖创作者登录，先到账号列表确认登录状态与素材要求。
