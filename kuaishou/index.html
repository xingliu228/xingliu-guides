01 / SETUP

安装与启动

安装即用：获取「星夜创作」安装包后双击安装，从桌面快捷方式启动。无需手动安装 Python 或其他运行环境；缺少 WebView2 组件时，安装器会自动联网补装。

  1. 双击「星夜创作」安装包，按提示完成安装；出现系统权限弹窗时确认允许。
  2. 从桌面快捷方式或开始菜单启动「星夜创作」，进入启动中心。
  3. 点击「启动本地服务」。首次启动会自动下载所需浏览器，请保持网络畅通并等待就绪。
  4. 服务就绪后点击「打开工作台」，在浏览器中进入本机工作台（地址 127.0.0.1:8000，指的是你自己的电脑，不是公共网站）。

完成标志：能看到工作概览，并打开「平台账号」页面。第一次列表为空是正常的。

日常启动与停止

日常从桌面快捷方式打开启动中心，一键启动本地服务。暂时不用时可收起到系统托盘，任务继续运行；需要完全停止时，在启动中心选择「停止并退出」。仅关闭网页并不会停止后台服务。

应用更新

应用会定期检查新版本；有可用更新时，右下角会出现更新提示，按提示下载安装即可。升级前会自动备份配置与数据库，已下载内容与账号资料保留；更新完成后重新启动，检查账号、配置和历史记录是否正常。

启动或连接异常时

先在启动中心查看运行记录与诊断信息，确认服务状态；再按常见问题排查。仍无法解决时，按文末方式导出运行日志联系我们。

02 / ACCOUNT

登录快手账号

入口：选择快手 → 平台账号 → 添加账号

  1. 把平台切换为「快手」，打开「平台账号 → 添加账号」。
  2. 按用途选择「扫码登录」或「创作者登录」：扫码用于读取、下载与监控；发布作品需要创作者登录。
  3. 在弹出的浏览器窗口中按提示完成扫码与确认，不要提前关闭窗口。
  4. 回到账号列表检测状态，确认昵称与状态正常。

完成标志：账号出现在列表中，状态检测正常，并能在创建任务时被选中。

登录失效时从账号列表重新登录，不要为了修复登录删除整个数据目录。

03 / FIRST RESULT

第一个任务：下载一条自己的作品

先用你自己拥有或获准保存的一条快手作品，验证「本地服务 → 账号 → 任务 → 文件」整条链路。

  1. 在快手复制自己一条作品的完整分享文案，不必手动删掉其中的文字。
  2. 打开「链接下载」，粘贴分享内容并选择刚登录的账号，其余选项先保留默认。
  3. 提交后等待结果，不要连续点击。
  4. 等待下载记录完成后，打开实际保存的文件确认可以播放。

完成标志：下载记录显示完成，实际文件能正常打开。链路已跑通，后面的功能都建立在这条链路上。

下一步：想持续发现新作品，看作品监控；想看互动内容，看评论监控。下载的详细说明见链接下载。

链接下载：保存已知作品

入口：链接下载

  1. 复制作品完整分享文案或链接，粘贴到输入框。
  2. 选择已登录账号与下载选项，提交后等待结果。
  3. 在下载记录查看状态与保存路径，成功后打开实际文件核对。

下载有断点续传和失败重试机制；链接失效或登录失效导致的失败，需要先修复原因再重试。默认下载内容位于 data/media/ 下，修改过下载目录时以界面配置的实际路径为准。

作品监控：持续发现新作品

入口：作品监控 → 新建作品监控

  1. 新建作品监控，填写创作者目标（完整分享文案或主页链接），选择可用的快手账号。
  2. 设置检查频率和自动下载范围；第一次先用一个目标测试，确认跑通后再增加。
  3. 在「监控目标」查看执行状态，在「作品记录」查看发现的内容。

为什么新建后看不到旧作品？默认监控订阅之后的新内容。没有新内容、尚未到检查时间，都会暂时没有记录，不代表监控失效。

完成标志：目标出现在列表中；执行后有检查状态，有符合条件的新作品时进入作品记录。不需要继续监控时暂停目标，不要只关网页。

评论监控

入口：评论监控 → 新建评论监控

  1. 按表单选择「指定作品」或「账号近期作品」目标类型，填写完整链接。
  2. 选择可用账号，检查频率保持默认或低频。
  3. 执行后到「评论记录」查看结果；空结果时依次检查登录状态、目标链接与筛选条件。

评论监控只负责读取和保存评论，不会自动发出回复；自动回复见自动评论。

发布作品

入口：发布 → 撰写内容；结果在「发布记录」查看

  1. 确认创作者登录有效，进入「发布」并选择发布账号。
  2. 添加素材与文案，检查预览和平台要求（素材类型与格式以表单提示为准）。
  3. 确认无误后仅提交一次，在「发布记录」观察进度。
  4. 到快手核对作品及审核状态。

遇到「结果待确认」：先到快手核对是否已经发出，不要直接重复提交。任务提交成功，不代表已通过平台审核或公开可见。

我的内容

入口：我的内容 → 选择账号 → 选择标签

  1. 进入「我的内容」，选择自己的快手账号。
  2. 按页面可见标签同步作品、关注或粉丝。
  3. 确认目标后再执行账号动作；出现冷却提示时先查看风控状态，等待恢复条件满足。

快手版的「我的内容」不含私信：支持范围是作品、关注与粉丝，不要按抖音或小红书的私信能力来预期使用。

自动评论

入口：自动评论 → 新建评论规则；审核在「任务与审核」

  1. 添加规则：填写执行账号、评论目标与评论模板；新建后规则先保持关闭。
  2. 试跑并检查生成的文案，完成需要的人工审核。
  3. 确认正确后再启用，保持低频并核对实际发送结果。

「已启用」不等于「立刻发送」。实际发送受审核与发送间隔约束；出现平台验证或拒绝提示时，先处理提示，不要连续重试。不需要时关闭规则，并检查队列里是否还有待处理任务。

NOTICE / 限制与注意

限制与注意

  • 不支持关键词批量采集和短视频弹幕监控；持续发现新内容请使用作品监控。
  • 「我的内容」支持作品、关注和粉丝，不应按抖音或小红书的私信能力预期使用。
  • 不是所有平台都能互相转发，以应用内实际提供的入口为准。
  • 发布要求创作者登录有效；提交成功不代表通过平台审核或公开可见。
  • 自动发送类任务受审核、间隔与风控冷却约束；遇到平台验证时先在当前窗口处理，优先降低任务规模与频率，而不是放开限制。
  • 本地任务依赖本地服务运行：关闭服务或电脑休眠后，任务不会继续执行。
FAQ / 常见问题

常见问题

浏览器查找快捷键：Windows / Linux 按 Ctrl + F，macOS 按 ⌘ + F，搜索错误关键词。

打开工作台提示连接失败

确认启动中心仍在运行、本地服务处于「运行中」，首次启动的依赖与浏览器下载已完成。尽量使用启动中心的「打开工作台」按钮进入。127.0.0.1 指本机，不要在另一台电脑上访问这个地址。

监控或评论结果为空

依次检查：账号登录是否有效、目标链接是否完整、筛选条件是否排除了结果。监控默认只看订阅后的新内容，没有新内容或未到检查时间时暂时没有记录，属于正常现象。

想按关键词批量采集怎么办

快手版不支持关键词批量采集。想持续盯一个创作者，使用作品监控；需要批量采集能力时，可参考站内的抖音版或小红书版教程。

发布失败或提示「结果待确认」

先确认创作者登录有效、素材符合表单要求；「结果待确认」时先到快手核对是否已发出，不要立即重发，以免重复发布。
