星流创作 / 图文教程

装在自己电脑上的内容工具，
选好平台，跑通第一个任务。

「星流创作」是一款桌面端内容工具：在本机登录你的平台账号，即可完成作品下载、内容监控、关键词采集、评论互动、发布与私信等操作。它不是云服务——登录态、任务与数据都保存在你自己的电脑上，关机或停止本地服务后，任务不会继续执行。

下载与安装先看四平台能力一览

选你的平台

四份教程分别对应四个平台，功能范围各不相同。按你常用的平台进入，从安装、登录到第一个任务，一步步跟着做即可。

抖音 扫码或创作者登录，先下载一条自己的作品，再使用作品监控、关键词批量采集、评论与弹幕、发布转发和私信。 进入抖音版教程 → 小红书 先分清主站登录与创作者登录，再使用笔记与关键词监控、批量采集、图集视频定时发布、评论互动与私信。 进入小红书版教程 → 快手 从账号登录和作品下载开始，逐步使用作品监控、评论监控、创作者发布、我的内容与自动评论。 进入快手版教程 → 视频号 围绕你自己的视频号：登录创作者助手，同步本账号作品、数据与评论，并发布内容、接收抖音作品转发。 进入视频号版教程 →

各平台能力以对应教程页的「能力速查」为准；星流创作只提供平台实际允许的操作，不承诺平台本身不具备的能力。

SETUP / 下载与安装

下载与安装

安装即用：获取「星流创作」安装包后双击安装，从桌面快捷方式启动。无需手动安装 Python 或其他运行环境；缺少 WebView2 组件时，安装器会自动联网补装。

  1. 双击「星流创作」安装包，按提示完成安装；出现系统权限弹窗时确认允许。
  2. 从桌面快捷方式或开始菜单启动「星流创作」，进入启动中心。
  3. 点击「启动本地服务」。首次启动会自动下载所需浏览器，请保持网络畅通并等待就绪。
  4. 服务就绪后点击「打开工作台」，在浏览器中进入本机工作台（地址 127.0.0.1:8000，指的是你自己的电脑，不是公共网站）。

完成标志：能看到工作概览，并打开「平台账号」页面。第一次列表为空是正常的，接下来去对应平台教程页登录账号。

日常使用：从桌面快捷方式打开启动中心，一键启动本地服务；暂时不用时可收起到系统托盘，任务继续运行；需要完全停止时，在启动中心选择「停止并退出」。仅关闭网页并不会停止后台服务。

UPDATE / 更新说明

更新说明

  1. 应用会定期检查新版本；有可用更新时，右下角会出现更新提示。
  2. 按提示下载并安装更新。升级前会自动备份配置与数据库，已下载内容与账号资料保留。
  3. 更新完成后重新启动应用，检查账号、配置和历史记录是否正常，再恢复任务。

更新前建议：暂停重要任务并停止本地服务；重要数据可再手动做一次备份——停止服务后，把 config.yaml 与整个 data/ 目录复制到数据目录之外的私人位置。备份包含 Cookie、私信等敏感信息，只保存在可信位置，不要上传公开网盘或外发。
